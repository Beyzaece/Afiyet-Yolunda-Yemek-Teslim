# 🍴 Afiyet Yolunda – Yemek Teslim Uygulaması  

**Afiyet Yolunda**, kullanıcıların mobil uygulama üzerinden yemek siparişi verip hızlı ve güvenilir bir şekilde teslim almasını sağlayan modern bir **yemek teslim sistemi**dir.  
[![Demo Videosu](https://img.youtube.com/vi/epXzVHc8cws/0.jpg)](https://youtu.be/epXzVHc8cws?si=TEMF_UGGKNcw-jqf)

---

## 🚀 Özellikler
- 📱 Kullanıcı dostu arayüz  
- 🍔 Menüden yemek seçme  
- 🛒 Sepet oluşturma  
- 🚚 Canlı teslimat takibi  
- 🔐 Güvenli kullanıcı girişi ve ödeme  

---

## 🛠️ Kullanılan Teknolojiler
- **React Native** (mobil arayüz)  
- **Firebase** (kimlik doğrulama & veritabanı)  
- **Expo** (hızlı geliştirme)  
- **Node.js / Express** (backend API – opsiyonel)  

---

## 📂 Proje Yapısı
Afiyet-Yolunda-Yemek-Teslim/
